# ONEBOX — Reference Layout Build

This version recreates the provided dashboard-style ONEBOX reference as a real responsive website.

## Layout included
- Fixed left sidebar on desktop
- Top global search
- Language selector
- Pro UI placeholders
- Large ONEBOX hero + SmartBox finder
- Popular Tools panel
- Tool/category statistics
- Category browser
- Featured tools
- SmartBox bottom workflow panel
- Full working tool grid
- Responsive mobile layout

## Functionality
The working tools from the previous ONEBOX build are preserved. Tool buttons open functional browser-based utilities.

## Important
- PDF tools load pdf-lib from jsDelivr and require internet.
- QR generation may use an external QR image service.
- Pro is UI-only until you connect payments/authentication/backend.
- Do not display fake user/revenue statistics.
